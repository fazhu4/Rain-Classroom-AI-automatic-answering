=== 网课自动答题工具 ===

【准备工作 - 获取 API Key（只需一次）】
  1. 打开 https://platform.deepseek.com 注册账号
  2. 登录后在左侧菜单找到 "API Keys"
  3. 点击 "创建新的 API Key"，复制生成的 Key

【每次使用 - 3 步开始答题】

  第 1 步：双击 start_edge.bat
    等待 Edge 浏览器自动启动（会先关闭已打开的 Edge 窗口）

  第 2 步：登录考试
    在新打开的浏览器中，打开考试网站并进入考试页面

  第 3 步：双击 AutoExamSolver.exe
    首次使用会提示你粘贴 API Key，粘贴后回车
    之后每次启动直接开始自动答题

【如何停止】
  按 Ctrl+C 可随时终止程序

【更换 API Key】
  用记事本打开 config.yaml，修改 api_key 那一行即可

【常见问题】
  - 提示"连接失败"：双击 start_edge.bat 重新启动 Edge，确保 Edge 以调试模式运行
  - 提示"未自动匹配到考试页面"：在控制台中输入考试页面对应的数字序号，按回车
  - 提示"请确保 config.yaml 与 exe 放在同一个文件夹"：不要单独移动 exe 文件

有解决不了的问题联系开发者
